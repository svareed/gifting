Curated ambient tracks go here as `ambient.mp3`.

Keep each one around 500 KB and self-hosted. The reference invitation this
product is modelled on inlined a 4.7 MB base64 MP3 into its HTML, so the page
weighed 4.7 MB before a single word rendered. Do not do that.

The music section is off by default and playback only ever starts from a real
user gesture, because Safari will not autoplay audio.
